# Netflix Top Genres & Movies Analysis

## Project Overview
This project explores Netflix movies and TV shows using Python to understand genre distribution, content trends, ratings, and patterns in the Netflix titles dataset.

## Objectives
- Identify the top 10 genres available on Netflix.
- Explore genre trends across release years.
- Analyze the distribution of content ratings.
- Practice data preprocessing, visualization, and machine learning classification.
- Experiment with a content-based recommendation approach.

## Dataset
The project uses `netflix_titles.csv`, which contains information about Netflix titles, including their type, title, director, cast, country, release year, rating, duration, genres, and description.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Workflow
1. Load and explore the dataset.
2. Inspect missing values and duplicate records.
3. Perform data preprocessing and transformation.
4. Analyze genre distribution and release-year trends.
5. Visualize content ratings and numerical relationships.
6. Experiment with classification algorithms.
7. Explore content-based recommendations using TF-IDF and cosine similarity.

## Files in This Repository
- `Internship Project.ipynb` — Jupyter Notebook containing the analysis and code.
- `netflix_titles.csv` — Dataset used in the project.

## How to Run
1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```

4. Keep the notebook and CSV file in the same directory.
5. Open the notebook and run the cells in order.

## Key Findings

- International Movies and Dramas are among the most frequently listed genres in the dataset.
- Comedies also have a strong presence in the Netflix content catalog.
- The genre distribution highlights the variety of movies and TV shows represented in the dataset.
- Visualizations help make content distribution and genre patterns easier to understand.
